# Spotify Clone

A Spotify-inspired music streaming web application built using HTML, CSS, and JavaScript. The project provides an interactive and responsive music player interface with audio controls and playlist functionality.

---

## 🚀 Features

- Play/Pause Music
- Next & Previous Song Controls
- Interactive Music Player UI
- Responsive Design
- Dynamic Audio Handling using JavaScript
- Playlist Functionality
- Smooth User Experience

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify (Deployment)
